# GitNomad edt2

> 노트북 하나, git 하나, 어디서나 발행.  

## 소개

GitNomad는 로컬에서 글을 쓰고 GitHub Pages로 발행하는 개인 퍼블리싱 시스템입니다.

서버도 없고, 구독료도 없고, 내 git 레포가 전부입니다.

## 특징

- **로컬 우선** — SQLite에 저장, 인터넷 없어도 글 쓰기 가능
- **GFM 지원** — 표, 코드블록, 체크박스 전부 됩니다
- **git push = 발행** — 버튼 하나로 세상에 올라갑니다
- **심플한 구조** — posts.json + .md 파일, 그게 전부

## 스택

| 로컬 | 웹 |
|------|-----|
| Python + Flet | GitHub Pages |
| SQLite | Tailwind CSS |
| GFM 에디터 | marked.js |

## 시작하기

```bash
cd gitnomad
python app.py
```
