# GitNomad 데이터베이스 설계  edt1

> 단순하게, 필요한 것만.

## 구조

GitNomad는 SQLite 두 테이블로 구성됩니다.

## 테이블

### category

| 필드 | 타입 | 설명 |
|------|------|------|
| id | INTEGER | 자동 증가 기본키 |
| name | TEXT | 카테고리 이름 |

### post

| 필드 | 타입 | 설명 |
|------|------|------|
| id | TEXT | 날짜+시간 기본키 (2025-05-28-1430) |
| title | TEXT | 글 제목 |
| category_id | INTEGER | 카테고리 외래키 |
| created_at | TEXT | 작성 시간 |
| updated_at | TEXT | 수정 시간 |
| content | TEXT | 본문 (GFM) |
| published | INTEGER | 0=작성중, 1=발행 |
| exported_at | TEXT | 마지막 export 시간 |

## 관계

```
category 1 ──< post N
```

## build.py 발행 조건

```sql
SELECT * FROM post
WHERE published = 1
AND (exported_at IS NULL OR updated_at > exported_at)
```

발행됐고, 수정된 글만 export합니다.
