# Run Metronome t1

> 팟캐스트, 유튜브, 음악과 **동시에** 사용하는 러너를 위한 케이던스 메트로놈

---

## 🏃 이런 분께 필요합니다

- 유튜브나, 팟캐스트 들으면서 조깅하는 러너
- 슬로우 조깅 케이던스(180 BPM)를 맞추고 싶은 분
- 사이클링, 수영 등 리듬 훈련이 필요한 분
- 음악을 끊지 않고 메트로놈을 쓰고 싶은 분

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🎚️ BPM 슬라이더 | 60 ~ 220 BPM 범위에서 자유롭게 조절 |
| 🔊 볼륨 조절 | 팟캐스트 음량에 맞게 틱 소리 조절 |
| 🎵 동시 재생 | 음악·팟캐스트·유튜브를 끊지 않고 함께 재생 |
| 📱 백그라운드 실행 | 화면이 꺼져도, 앱이 백그라운드여도 계속 작동 |
| 🛒 광고 제거 | 일회성 구매로 광고 없는 환경 |

## 🗒️ 사용 방법

1. 앱 실행
2. BPM 슬라이더로 케이던스 설정 (슬로우 조깅 권장: **170~180 BPM**)
3. 볼륨 조절
4. ▶ 시작 버튼 탭
5. 폰을 주머니에 넣고 뛰기 🏃

---

## 💡 케이던스 가이드

```
입문자     : 160 ~ 165 BPM
일반 조거  : 165 ~ 175 BPM
슬로우 조깅: 180 BPM (권장)
숙련 러너  : 180 ~ 200 BPM
```
